# Opervia — Service Compliance

Service Compliance is a mobile-oriented software solution developed by **Opervia** for the management and traceability of outsourced service compliance.

The project initially focuses on B2B outsourced cleaning services. Its purpose is to connect service planning, operational obligations, field execution, evidence, compliance evaluation, deviations, corrective actions, and reporting within a traceable service history.

The initial target users are:

- Supervisors and coordinators of outsourced cleaning services.
- Field cleaning operators.

## Project Report

This repository contains the documentation and software design artifacts developed for the **Service Compliance** project as part of the *Aplicaciones para Dispositivos Móviles* course.
